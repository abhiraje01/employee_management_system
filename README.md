# Employee Management System

# Project Description
Employee Management System developed using Spring Boot, Spring Data JPA, Hibernate, and MySQL.

# Features
- Employee CRUD Operations
- User Registration
- User Login
- Pagination and Sorting
- REST APIs
- MySQL Database Integration

# Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Postman

# API Testing
APIs tested using Postman.
